# Frontend Mentor - Blog preview card solution

This is a solution to the [Blog preview card challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/blog-preview-card-ckPaj01IcS). Frontend Mentor challenges help you improve your coding skills by building realistic projects. 

### Built with

- Semantic HTML5 markup
- CSS custom properties
- Flexbox

### What I learned

This challenge gave me a better idea of how flexboxes work, the smantic html and hover options on the whatver you want to apply it on. After working on previous labs and projects this gave me a better grasp on flex boxes and how to manipulate the contents within it. I'm really proud of the fact that my project replicates the jpg image provided completely.
